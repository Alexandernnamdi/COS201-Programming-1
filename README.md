## Project Overview
This project contains my first Java programming exercise. It demonstrates how to create a Java application, display text in the console and include personal academic information in a program.

## Learning Objectives
- Understand the basic structure of a Java program.
- Learn how the `main()` method works.
- Display messages using `System.out.println()`.
- Compile and execute a Java source file.
- Practise managing source code with GitHub.

## Development Environment

## How to Compile and Run

**Compile the program:**
```bash
javac week02/Helloworld.java
```

**Run the program:**
```bash
java week02.Helloworld
```

## Expected Result
When executed successfully, the program displays a welcome message, course details and my student information in the terminal.
